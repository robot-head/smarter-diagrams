Diagram layout compiler

Combine hierarchical tiers, explicit row alignment, typed record ports, and progressive views in one file.

  1. Orthogonal diagram routing

    Sugiyama layering, Brandes-Kopf alignment, and A* channels separate edges and labels.

  2. Class and schema diagrams

    Render typed UML compartments, SQL tables with pinned ports, and highlighted code blocks.

    DGcluster.dgm class 
    cr: "PostgresCR" [class] {
  port pods: "int32"
  port state: "Ready"
}
q: "```sql\nSELECT 1\n```"
    Typed fields align with ports.

    Reveal detail progressively with declarative views and elliptical boundary zones.
